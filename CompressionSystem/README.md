# Multi-threaded Compression System

## Description
This project is a TCP-based file compression system using C# and Windows Forms.

The system consists of:
- Multi-threaded Compression Server
- Client Application with UI

## Features
- Send file size then file data
- Compress files using GZip
- Send compressed file back to client
- Multi-threaded server using Task.Run
- Multiple clients supported simultaneously

## Technologies
- C#
- TCP Sockets
- Windows Forms
- GZipStream

## How To Run
1. Run the server project
2. Click Create Server
3. Click Start Server
4. Run one or more client projects
5. Connect and send files
